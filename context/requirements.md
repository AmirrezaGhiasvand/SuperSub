# Requirements

SuperSub runs locally, uses English layout and Persian RTL subtitle text. Required selectors: installed model, source language, maximum words per cue (1–30, default 8). Preserve colloquial speech. Include video preview, editing, history, cancellation, glossary hints and reflow without ASR. No batch processing, translation, diarization or burned-in video in v1. Original accepted architecture remains the target; deviations are recorded in current-status.md.
